## Navigation policy

| Action | Scroll and focus |
| --- | --- |
| Primary navigation, including selecting the current primary page | Start at top; focus destination heading; current-page selection replaces history |
| Browser Back/Forward | Restore the saved offset for that history entry; focus main without moving it |
| Same-chamber detail tab | Preserve offset and focus; tab selection replaces the detail entry |
| Explicit Back to Incubators | Restore the last list offset; focus main |
| Primary Incubators button | Start at top, even when a previous list offset exists |
| Lazy route | Wait until destination content replaces the loading placeholder before applying focus/offset |

Saved offsets are in memory for the mounted app session. A reload does not restore
this map. Browser bounds clamp offsets when the destination becomes shorter.
The hook restores the browser's original scroll-restoration setting on unmount.
