Local automatic cutoff. The ESP32 turns the motor signal off when the timer ends, or after 5 seconds without browser heartbeat. Hiding or leaving this page requests Stop. Stop may leave the tray tilted; it does not return it home. Keep the existing mains connections enclosed and do not adjust wiring while powered.
Only the tray can be switched on. Heater, mist and fans stay commanded off. This separate sketch pauses sensor, display and cloud services; main firmware is restored afterward.
